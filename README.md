# 🚀 IMOCHA - AI-Driven Incident-to-Status Automation Platform

> An intelligent platform that detects incidents, analyzes their severity, correlates related events, and automatically generates status page updates while notifying stakeholders in real time.

---

## 📌 Overview

IMOCHA is an AI-powered Incident-to-Status Automation Platform designed to simplify incident management by automating the complete workflow—from incident detection to public communication.

The platform continuously monitors incoming incidents, correlates related events, classifies their severity, and generates meaningful status updates automatically. It also keeps users informed through instant notifications.

---

## ✨ Features

- 🔍 Detect incidents from multiple sources
- 🤖 AI-powered incident analysis
- 📊 Incident dashboard with analytics
- 🚨 Automatic severity classification
- 🔄 Incident correlation
- 📝 Auto-generated status page updates
- 📢 Real-time notifications
- 📈 Analytics Dashboard

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/<your-username>/IMOCHA.git
```

### Navigate into the project

```bash
cd IMOCHA
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open your browser and visit

```
http://localhost:5173
```
